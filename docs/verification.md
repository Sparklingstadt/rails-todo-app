システムテストでは、追加 → 再読み込み → 編集 → 完了 → 完了タブで表示 → 未完了へ戻す → 削除のキャンセル → 削除を確認しました。空白だけのタイトルに対する日本語エラーと入力保持、モバイルでの追加・横はみ出しがないことも確認しています。

ブラウザーのコンソールにエラー・警告はありませんでした。スクリーンショットは `docs/screenshots` に保存しています。

依存関係の監査は実施時点の情報です。使用したruby-advisory-dbは2026-09-16更新、commit `44784c295391577f25d198a9205eae4ba73ec4da`。今後もCIなどで監査を再実行します。

開発中にJSON 3とRails 8.1の互換性問題を検出し、JSONを2系（lockfileでは2.21.2）に制限しました。画面内の移動リンクは通常のアンカー移動にして、フォームへの移動時にTurboのページ取得で入力内容が失われる経路を避けています。

GitHub上のCI実行・本番デプロイ・複数ユーザー利用・他OSでの実行は未検証です。この初版はローカル1人用で、認証・認可は次の開発段階です。

## 単体・E2Eテストの追加（2026-09-19）

単体テスト11件とE2Eテスト7件を追加しました。アプリ本体の変更はありません。

単体ではDBの制約、並び順の同値条件、うるう日、年越し、日本時間0時の期限表示を補いました。E2Eでは全項目の保存・再読込、期限のクリア、不正な編集からの修正、絞り込みと進捗、削除・編集キャンセル、最後のタスク削除、初回追加、HTML文字列の表示、長文を含むモバイル表示と下書き保持を追加しました。

E2E最終実行のランダムseedは29638、単体＋HTTPリクエストは53587です。詳細な実行手順は [テストガイド](testing.md) を参照してください。既存のCI定義でも追加ファイルが検出されますが、GitHubでの実行はまだ行っていません。
